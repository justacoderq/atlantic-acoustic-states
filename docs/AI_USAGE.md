# Generative-AI use record

Generative AI assisted with:

- Extracting and organizing the supplied project materials and auditing data
  files.
- Repository scaffolding and documentation.
- Implementing/debugging acoustic loading, preprocessing, feature generation,
  PCA, K-means evaluation, and experiment automation.
- Creating plots and generated result summaries from the included acoustic
  dataset, plus acoustic-only temporal and presentation visuals.

The reported baseline metrics and figures were produced by running the
repository script on the included data; they were not manually invented.
The team must independently review the code and decide the final research
question, abstract representation, methods, evaluation criteria, experimental
design, interpretation, and conclusions. In particular, the baseline's
silhouette-based choice of `k` is a reproducible exploratory default, not a
final scientific decision. Jacob's animal/GMM and Parker's vessel/weather/
density work are not implemented in this branch. Add future AI assistance to
this file and identify which code, analysis, or writing it affected.
