# Generative-AI use record

Generative AI assisted with:

- Extracting and organizing supplied project materials, auditing data files,
  and creating repository scaffolding and documentation.
- Implementing and debugging the acoustic baseline: loading, preprocessing,
  feature generation, PCA, K-means evaluation, automation, and plots.
- Creating acoustic-only temporal summaries and presentation visuals.
- Reviewing the vessel/weather source data and drafting the corresponding audit
  and hourly-table build script with Parker.

The reported baseline metrics and figures were generated by running the
repository scripts on the included data. The team is responsible for
independently reviewing the methods, evaluation criteria, experimental design,
interpretations, and conclusions. The baseline's silhouette-based choice of
`k` is an exploratory, reproducible default, not a final scientific decision.
Jacob's animal-data audit and exploratory GMM work are included below.
